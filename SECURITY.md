# Security Policy

OPlusAutoHR modifies system display behavior and interacts with SurfaceFlinger,
HWC and vendor display paths. Please distinguish ordinary compatibility bugs
from security-sensitive issues.

Use GitHub Issues for normal compatibility problems, mode-switch failures,
hotplug bugs and WebUI problems.

Please avoid publishing exploit details or sensitive information if an issue
could enable privilege escalation, persistent denial of service, unintended
access to protected data, or another security impact beyond the expected
experimental display behavior.

Do not include account tokens, private keys, device serial numbers, private
logs, personal identifiers or other secrets in public reports.
