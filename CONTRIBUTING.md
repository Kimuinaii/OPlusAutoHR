# Contributing to OPlusAutoHR

Thanks for helping test or improve OPlusAutoHR.

## Before opening an issue

- Reboot and confirm the issue is reproducible.
- State whether External Pacesetter is enabled.
- Include device, Android/ROM version, SoC, dock/adapter, cable/protocol,
  monitor model, target resolution/refresh rate, Root solution and module
  version.
- Include `oahctl status` and relevant `engine.log` output when possible.
- Remove private information from logs before posting.

## Pull requests

Keep OPlus/OxygenOS and Xiaomi/HyperOS paths isolated where possible. Avoid
hard-coding physical display IDs, mode IDs, resolutions or refresh rates.
Explain device/ROM assumptions in the pull request description and include
real-device test results when available.

By submitting a contribution, you agree that your contribution may be
redistributed under the project's current Source Available License unless a
separate agreement is made.
